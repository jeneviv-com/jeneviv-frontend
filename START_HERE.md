## 🚀 5-Minute Setup

### Terminal 1: Backend
```bash
cd jeneviv-backend
pnpm install
pnpm db:migrate
pnpm dev
```

### Terminal 2: Webapp
```bash
cd webapp
pnpm install
echo "VITE_API_URL=http://localhost:3001" > .env.local
pnpm dev
```

### Access
- **Webapp**: http://localhost:5173
- **Backend**: http://localhost:3001
